# MLP / Consors to Portfolio Performance Converter

Python scripts to convert MLP and Consors bank data to a CSV file understood by [Portfolio Performance](https://github.com/buchen/portfolio).

## Input

- `mlp_to_portfolio_performance_converter.py`: a CSV file generated by exporting transaction data from an MLP bank account.
- `consors_to_portfolio_performance_converter.py`: a CSV file generated by exporting an account's "Umsatzübersicht" from Consors.

## Output

A CSV file that can be imported by Portfolio Performance.

## Requirements

Python 3.2 or higher.
On Linux, you need to install the locale 'de_DE':

```bash
sudo locale-gen de_DE
```

## Instructions

1. Install Python 3.2 or higher.
1. Download the current release and extract it to a folder `C:\User\your_name\mlp-to-portfolioperformance-converter`

Then follow the steps for your bank below.

### MLP

1. Open the transactions of the clearing account in MLP Financepilot Banking.
Set the desired time period. Export the data as CSV (top right, the icon above
"Current") and save the file as
`C:\User\your_name\Downloads\Umsaetze.csv`.
1. Press Windows key + X.
1. Select Windows PowerShell
1. Navigate to `cd C:\User\your_name\mlp-to-portfolioperformance-converter`.
1. Run the script with `python mlp_to_portfolio_performance_converter.py ~\Downloads\Umsaetze.csv`.
1. Check the output for errors. If everything went smoothly, there should now
be a file `~\Downloads\Umsaetze_converted` that can be imported into Portfolio Performance.

### Consors

1. Export the account's transactions from Consors as an "Umsatzübersicht" CSV
file and save it, e.g. as `C:\User\your_name\Downloads\Umsatzuebersicht.csv`.
1. Press Windows key + X.
1. Select Windows PowerShell
1. Navigate to `cd C:\User\your_name\mlp-to-portfolioperformance-converter`.
1. Run the script with `python consors_to_portfolio_performance_converter.py ~\Downloads\Umsatzuebersicht.csv`.
1. Check the output for errors. If everything went smoothly, there should now
be a file `~\Downloads\Umsatzuebersicht_converted.csv` that can be imported into Portfolio Performance.
